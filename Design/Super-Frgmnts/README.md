# SUPER FRGMNTS // Canonical Design Index

The canonical production runtime is
[`super_frgmnts.html`](../../super_frgmnts.html) on `main`. Design packages,
manifests, contracts, and approval artifacts in this directory support that
runtime; they are not alternate sources of truth.

  traversal, systems, population, and promotion gate
- [Episode 01 release manifest](Releases/episode-01-unified-v1.json) — public

- [Current asset intake](ASSET-INTAKE-2026-07-26.md) — normalized runtime

Future SUPER FRGMNTS work should preserve both the current game contract and
the platform baseline. Portability improvements are made incrementally when a
feature touches the relevant seam; they do not require a speculative rewrite.
