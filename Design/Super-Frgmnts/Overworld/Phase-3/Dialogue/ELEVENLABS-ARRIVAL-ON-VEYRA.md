## Voice direction

### Speaker 1 // Dras Ehdre

Weathered and formidable; an older Coreworks foreman with a low, steady,
deliberate delivery. Grief and exhaustion remain controlled beneath practical
authority. His humor is dry. He must not sound frail, theatrical, or villainous.

### Speaker 2 // Aryn Sol-Mavi

Composed, alert, and professionally direct; a capable Signal Ranger accustomed
to pressure. Her warmth is restrained, her wit is dry, and her authority is
quiet rather than aggressive. She must not sound robotic, bubbly, or
melodramatic.

### D02 // Speaker 2 // Aryn

### D05 // Speaker 1 // Dras

```text
[guarded] Plain speech wouldn’t have made it off-world.
```

### D06 // Speaker 2 // Aryn

```text
[sharply curious] Excuse me?
```

### D07 // Speaker 1 // Dras

```text
[brushing it aside, disappointed] Never mind. I hoped the Fleet would send more than one ranger.
```

### D08 // Speaker 2 // Aryn

```text
[controlled and factual] They classified Veyra as a Class Six containment risk. No deployment.
```

### D09 // Speaker 1 // Dras

```text
[with contained frustration] Veyra supplied half the Arca System with Vesperite. If that doesn’t qualify as a priority, the Fleet has forgotten what keeps its lights on.
```

### D10 // Speaker 2 // Aryn

```text
[firmly] They haven’t forgotten.
```

**NON-SPOKEN VISUAL BEAT:** The ground trembles. Dust slips from the outpost
canopy. Aryn studies the signal on her wristpad.

### D11 // Speaker 1 // Dras

```text

```

**NON-SPOKEN VISUAL BEAT:** Aryn disconnects her wristpad from Central Command.
Its cyan signal goes dark.

### D12 // Speaker 2 // Aryn

```text
[quietly, with difficult honesty] Because the Fleet rejected your call. I was in the room when they buried it.
```

### D13 // Speaker 1 // Dras

```text
[surprised, reassessing her] And yet here you are.
```

### D14 // Speaker 2 // Aryn

```text
[steady and unequivocal] On my ship. On my authority. Central doesn’t know I landed.
```

### D15 // Speaker 1 // Dras

```text
[with wary admiration and dry humor] Then you’re braver than I thought. Or maybe you’re just terrible at following orders.
```

### D16 // Speaker 2 // Aryn

```text
[dryly] Those aren’t mutually exclusive.
```

### D17 // Speaker 1 // Dras

```text
[with faint, reluctant amusement] No. I suppose they aren’t.
```

## Batch 2 // The Coreworks // D18–D24

### D18 // Speaker 2 // Aryn

```text
[focused and authoritative] Start at the beginning. What happened beneath the Coreworks?
```

### D19 // Speaker 1 // Dras

```text
[grave, deliberately recounting the loss] Eighteen months ago, a drill team in the Deepworks broke into a seam that wasn’t on any survey. Communications failed. Our Seam Integrity team went down to investigate. Then the entire shift disappeared. More than two hundred women and men. Gone.
```

**NON-SPOKEN VISUAL BEAT:** Aryn’s expression hardens. She lets the silence
remain.

### D20 // Speaker 1 // Dras

```text
[somber and controlled] We sent team after team to investigate. Only one person made it back to the portal alive. What they described was clear: something had infested the Coreworks. By then, the atmospheric stabilizers had been destroyed.
```

### D21 // Speaker 2 // Aryn

```text
[alert, assessing the danger] Is it contained below the surface?
```

### D22 // Speaker 1 // Dras

```text
[grimly] For now. But the air below is lethal, and whatever killed those workers is still moving through the facility.
```

### D23 // Speaker 1 // Dras

```text
[weary, with grief held in check] When production stopped, so did the Vesperite payments. The economy collapsed in a week. Anyone who hadn’t already left took what they could and found work off-world.
```

### D24 // Speaker 2 // Aryn

```text
[sympathetic but resolute] I’m sorry for your people. But you’re asking me to enter a poisoned facility after something erased two hundred workers. If you want my help, we speak plainly.
```

## Batch 3 // The assignment // D25–D36

### D25 // Speaker 1 // Dras

```text
[with dry approval] Disobedient and wise. Who knew?
```

### D26 // Speaker 2 // Aryn

```text
[dryly, then firmly] Apparently, just what Veyra needs. So we’re agreed. Tell me everything you know.
```

### D27 // Speaker 1 // Dras

```text
[quietly intense] You’re probably wondering why I stayed. The failures weren’t random. Before each one, the same pulse moved through the Vesperite seams. I don’t think this is an accident. I think it’s a response.
```

### D28 // Speaker 2 // Aryn

```text
[troubled and probing] A response? You make it sound like something down there is answering us. Whose response?
```

### D29 // Speaker 1 // Dras

```text
[plainly, with a warning beneath the offer] That’s what I’ll pay you to find out. If you accept—and if you survive—there are entire crates of Galactic Credits below. Whatever you recover is yours.
```

### D30 // Speaker 2 // Aryn

```text
[sincere, then lightly wry] My mind was made up before the credits. But I won’t say no to honest money.
```

### D31 // Speaker 2 // Aryn

```text
[ready for action] Where do I start?
```

### D32 // Speaker 1 // Dras

```text
[clear and operational] The Foundry. Bring both atmospheric stabilizers online and clear the infestation. The pulse fractures Vesperite along its path. Recover the fragments—their residual harmonics may tell us where it began.
```

### D33 // Speaker 2 // Aryn

```text
[cautiously] And the portal?
```

### D34 // Speaker 1 // Dras

```text
[flatly] It still opens.
```

**NON-SPOKEN VISUAL BEAT:** Dras looks toward the dormant portal.

### D35 // Speaker 1 // Dras

```text
[low and ominous] It just hasn’t brought anyone back.
```

### D36 // Speaker 2 // Aryn

```text
[confident, with restrained resolve] Then let’s improve its record.
```

**NON-SPOKEN VISUAL BEAT:** The Coreworks portal begins to ignite.
