# SUPER FRGMNTS expansion art prototypes

These files are visual-direction candidates, not production game assets.

## Foundry prototype v1

- `foundry-vertical-expansion-imagegen-raw-v1.png` is the unmodified built-in
  ImageGen result at 1182 × 1330.
- `foundry-vertical-expansion-prototype-v1.png` is normalized to 1672 × 1882.
  Its y=941–1120 transition is blended into the source, and every pixel from
  y=1121 through y=1881 is restored exactly from
  `Images/Builder/signal-foundry-bg.png`.
- `foundry-vertical-expansion-prototype-v1-prompt.txt` records the generation
  prompt.

The prototype successfully establishes palette, atmosphere, material language,
and vertical scale. It simplifies the collision guide into broad mezzanine
tiers, so it must not be wired into the game until the final collision plan is
reconciled with the visible openings and walkable edges.

The live game does not reference anything in this directory.
