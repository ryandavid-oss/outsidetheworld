# Super Frgmnts Controller Selection Audit

Audited against `super_frgmnts.html` for a standard-mapped PS4 controller.
The complete episode can be played without a mouse or touch screen.

## Selectable surfaces

| Surface | PS4 controller path | Result |
| --- | --- | --- |
| Load Game gate | Cross | Loads the game and proceeds to the title screen. |
| Title: Start | Cross | Starts Arrival on Veyra. |
| Title: difficulty | Triangle | Toggles Normal and Hard Mode. |
| Approach / Planet Veyra interstitials | Cross or Options | Skips or continues the transition. |
| Dialogue cards | Cross | Advances the current card. |
| Dialogue skip menu | Circle | Opens the confirmation panel; Circle closes it. |
| Dialogue skip confirmation | D-pad or Left Stick, then Cross | Moves between Keep Listening and Skip Scene, then confirms the highlighted choice. Keep Listening is the safe default. |
| Mission, retry, replay, return, and route cards | D-pad or Left Stick, then Cross | Selects every enabled visible action, including secondary actions when the primary action is unavailable. Circle cancels a route-entry card. |
| Seam Hunter interstitial | Cross or Options | Skips the encounter announcement. |
| Prism installation comic | Cross, Square, or Triangle | Advances a panel. Circle or Options skips the comic. |
| Pause root | Options | Opens Pause. D-pad or Left Stick selects; Cross confirms; Circle or Options resumes. |
| Pause: PACK Configuration | D-pad or Left Stick, then Cross | Opens the PACK screen. Triangle is also a direct shortcut. |
| Pause: Sound | D-pad or Left Stick, then Cross | Toggles game sound without using the header button. |
| Pause: Restart Checkpoint | D-pad or Left Stick, then Cross | Restarts the current checkpoint. |
| Pause: Return to Title | D-pad or Left Stick, then Cross | Performs the master reset and returns to the title. |
| PACK modules | D-pad or Left Stick, then Cross | Highlights and toggles every discovered module. Circle or Triangle returns to Pause; Options resumes. |
| Gameplay | Left Stick or D-pad, Down, Cross, Square/R1/R2, Triangle, Options | Covers movement, interaction/drop, jump/Jet Assist, fire, PACK, and Pause. |

## Header buttons

The visible Pause, Sound, Restart, and Title buttons remain available to mouse,
keyboard, and touch users. A controller player does not need to focus the page
header: all four functions are available from Options and the Pause menu.

## Audio note

Cross now dismisses the initial Load Game gate. Browser autoplay policy can
still leave audio muted until a browser-recognized keyboard, pointer, or touch
activation on some device/browser combinations. That browser limitation does
not block the title screen or any gameplay control.

## Touch

Touch controls remain supported in landscape but are optional. No episode
choice, confirmation, menu, dialogue, cinematic, or gameplay action requires
touch.
