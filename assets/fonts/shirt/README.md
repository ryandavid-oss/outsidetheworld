# Shirt artwork fonts

These unmodified Latin WOFF2 files come from the Google Fonts distribution.
They are self-hosted and loaded only when their typeface is used. The associated
SIL Open Font License files retain each family's copyright and reserved names.

Inter, Fira Code, and Merriweather use the existing core declarations in
`../otw-fonts.css`. These additional declarations are in `../shirt-fonts.css`.

Imported on October 9, 2026. Fraunces uses optical size 72; IBM Plex Mono
uses weight 600, and the other additional faces use weight 700.
